# 사주풀이 앱 서비스 계획서

## 1. 서비스 개요
| 항목 | 내용 |
|---|---|
| 서비스명 | 사주풀이 (saju-fortune) |
| 한 줄 소개 | 생년월일시만 입력하면 사주팔자·오행·평생운을 한 화면에서 보여주는 모바일 앱 |
| 형태 | iOS·Android 앱 + 웹 (Expo 하나로 동시 지원) |
| 수익 모델(향후) | 무료 평생사주 → 유료 상세풀이·궁합·AI 1:1 해석 |

## 2. 문제와 기회
- 기존 운세 사이트는 PC 시절 화면 구성에 광고·메뉴가 많아 모바일에서 결과를 읽기 불편하다.
- 대부분 회원가입이나 결제를 먼저 요구해서 가볍게 한번 보고 싶은 사용자가 이탈한다.
- **기회**: 가입 없이 빠르게, 모바일에 맞춘 카드형 결과와 공유 기능을 제공한다.

## 3. 타깃 사용자
- **주 타깃**: 20~30대. 재미로 운세를 보고 친구에게 공유하는 사용자
- **부 타깃**: 사주 용어(천간·지지·오행)를 쉽게 배우고 싶은 입문자

## 4. 핵심 가치
1. **빠름**: 입력 1화면, 결과 1화면
2. **쉬움**: 한자에 한글 독음과 오행 색상을 함께 표시
3. **안심**: 서버로 개인정보를 보내지 않고 기기 안에서 계산

## 5. MVP 기능
| # | 기능 | 설명 | 상태 |
|---|---|---|---|
| F1 | 정보 입력 | 이름, 성별, 양력/음력(윤달), 생년월일, 태어난 시(12시진·모름) | ✅ |
| F2 | 사주명식 | 시·일·월·년주 4기둥 8글자, 한글 독음, 오행 색 | ✅ |
| F3 | 오행 분석 | 목·화·토·금·수 개수 막대그래프 | ✅ |
| F4 | 평생사주 풀이 | 총평, 초년·중년·말년운, 성격·애정·재물·건강운, 오행 균형 조언 | ✅ |
| F5 | 결과 공유 | OS 공유 시트로 사주와 총평 공유 | ✅ |

### 풀이 규칙
- **총평·성격·애정·재물·건강**: 일간(日干, 태어난 날의 천간) 10종별 해석
- **초년/중년/말년운**: 년주/월주/시주(시간을 모르면 일주) 지지의 오행별 해석
- **오행 균형**: 가장 많은 오행의 과잉 조언과 가장 적은 오행의 보완 조언

## 6. 화면 흐름
```
홈(index) ──[평생사주 보기]──▶ 정보 입력(input) ──[결과 보기]──▶ 결과(result)
                                                                 ├ 사주명식
                                                                 ├ 오행 분석
                                                                 ├ 풀이 카드 9개
                                                                 └ 공유하기
```

## 7. 기술 스택
| 영역 | 선택 | 이유 |
|---|---|---|
| 앱 | Expo SDK 57 + React Native + TypeScript | 코드 하나로 iOS·Android·웹, Expo Go로 즉시 실행 |
| 라우팅 | Expo Router (`src/app`) | 파일 기반 라우팅, 웹 정적 빌드 지원 |
| 만세력 | `lunar-javascript` | 절기 기준 4주 계산, 음력·윤달 변환 |
| 레퍼런스 수집 | Python + Firecrawl | 폼 제출이 필요한 페이지를 브라우저 actions로 수집 |
| 배포 | GitHub CLI + GitHub Pages | `gh`로 저장소 생성·푸시, 웹 빌드를 Pages로 공개 |

## 8. 일정 (실습 단위)
| 단계 | 작업 | 산출물 |
|---|---|---|
| 1 | 폴더 만들기 | `saju-fortune/`, git 저장소 |
| 2 | 계획 세우기 | `docs/PLAN.md` |
| 3 | 폴더 구조 정하기 | `README.md`의 폴더 구조 |
| 4 | 레퍼런스 주기 | `docs/REFERENCES.md`, `references/crawl_unsin.py` |
| 5 | 구현 | `src/` 화면·사주 계산·풀이 데이터 |
| 6 | GitHub CLI 배포 | GitHub 저장소 + Pages URL |

## 9. 완료 기준
- 양력 1990-05-15 미시를 입력하면 `癸未 庚辰 辛巳 庚午`가 나온다(레퍼런스 사이트의 십신 배치와 일치).
- 음력과 윤달을 입력하면 양력 날짜가 함께 표시된다.
- 존재하지 않는 날짜는 입력 화면에서 막힌다.
- `npx tsc --noEmit`, `npx expo export -p web`이 성공한다.
- GitHub Pages URL에서 웹 버전이 동작한다.
